# Still Alive

Jibo sings Still Alive, with the amber terminal screen from the end credits typing the lyrics as he sings.

## How it works

1. Open **Still Alive** from Jibo's main menu.
2. The song plays, and the left side of the screen types each line in time with Jibo's singing. Credits scroll on the right, with ASCII art underneath.
3. It goes back to Jibo's eye when the song ends. Swipe down to stop early.
